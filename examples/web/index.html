video-utils

動画まわりの小さな道具（計算だけ・依存なし）。Small helpers for video URLs, mp4 files and subtitles.

npm install @shiodome47/video-utils

1. 動画の URL Video URLs

YouTube・Dropbox・ふつうの URL を貼ってください。
Paste a YouTube, Dropbox or any other URL.

2. 字幕（SRT・WebVTT） Subtitles

字幕ファイルの中身を貼るか、ファイルを選んでください。
Paste subtitles or pick a .srt / .vtt file.

開始 start終了 end文 text

3. mp4 の目次（faststart） mp4 faststart

mp4 を選ぶと、中の部品の並び（ftyp・moov・mdat など）を出します。目次（moov）が後ろにあれば、前へ移した動画を作れます。ファイルはこの端末の中だけで扱い、どこにも送りません。
Pick an mp4 to see its top-level boxes. If moov comes after mdat, a fixed copy is made. The file never leaves this device.
